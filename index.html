Частые вопросы

Сколько стоит бот?
Зависит от сложности. Простой бот-модерация — от 2 500 ₽. Бот с экономикой, играми, сложной логикой — от 7 000 ₽. Точную цену скажу после обсуждения задачи.
Сколько времени займёт разработка?
Простой бот — 1-3 дня. Средний — 3-7 дней. Сложный проект — 1-3 недели. Сроки обсуждаем заранее.
Какие технологии используешь?
Discord.js, Node.js, JavaScript для ботов. HTML, CSS, JavaScript для сайтов. Python для скриптов и автоматизации.
Есть ли поддержка после сдачи?
Да. Если что-то сломалось по моей вине — исправляю бесплатно. Мелкие правки — тоже бесплатно. Новые функции — за отдельную плату.
Как проходит оплата?
50% предоплата, 50% после сдачи проекта. Для крупных проектов возможно разделение на этапы.
